# Open Media Downloader — design patch

Скопируй содержимое этого архива поверх текущего рабочего репозитория расширения.

Этот patch не заменяет логику скачивания. Из JS изменён только `content/icons.js`, и там изменён CSS, который инжектируется для кнопок на странице.

Перед проверкой убедись, что в твоём рабочем репозитории остался файл:

- `vendor/ffmpeg/core/ffmpeg-core.wasm`

В repomix-архиве этого бинарника не было, поэтому patch нужно применять поверх оригинального проекта, а не использовать как самостоятельное расширение.
