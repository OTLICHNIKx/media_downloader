# Privacy Policy draft — Open Media Downloader

Open Media Downloader is a browser extension that helps users detect and save open media streams available on pages they visit.

## Data processed locally

The extension may process page URLs, media URLs, stream metadata, filenames, and diagnostic information in the user's browser to provide its core functionality.

## Data storage

The extension may store local preferences, such as whether download buttons are hidden on a specific site. This data is stored locally in the browser extension storage.

## Data sharing

The extension does not sell user data. The extension is not designed to send browsing history, media URLs, or downloaded files to an external analytics or advertising service.

## Downloads

When the user chooses to download media, the extension passes the selected file URL and filename to the browser download manager.

## User responsibility

Users should only download content they own, content that is openly downloadable, or content they otherwise have permission to save. The extension is not intended to bypass DRM, paid access, login restrictions, or platform protections.
